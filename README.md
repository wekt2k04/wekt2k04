# TSETSE Komla Edem Wilfried

AI / Data Engineering student (5th-year engineering cycle, Morocco). I build systems that sit
at the boundary most "AI projects" skip — the part between a model that works in a notebook and
a model that runs, is tested, and stays honest about what it doesn't know.

Three things I keep coming back to:
- **Agentic systems you can trust** — RAG pipelines and local-LLM orchestration with the
  guardrails encoded in code, not just the prompt (retrieval, RBAC, anti-hallucination).
- **Applied deep learning on real signal** — medical imaging, computer vision, time-series
  forecasting — evaluated honestly, including where it's weak.
- **Production engineering, not demos** — typed backends, atomic state transitions under
  concurrency, real test suites, systems that get deployed and used, not just committed.

Currently preparing graduate-school applications in AI / Data Engineering for Fall 2027.
